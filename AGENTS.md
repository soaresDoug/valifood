# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v57.0.0/ before writing any code.

## Git conventions

- Commit messages are always written in **English**, following
  [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/):
  `<type>(<scope>): <short imperative description>`.
- Types used: `feat`, `fix`, `docs`, `refactor`, `test`, `chore`.
- Keep the subject on a single line (the repository history uses single-line subjects).
- Examples: `fix(tabs): make bottom tab bar height safe-area aware (labels clipped on iOS)`,
  `feat(home): center empty state vertically`.
